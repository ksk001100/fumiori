# 語の組合せを調べる対照例 v13

`pairs.tsv` はCodexが作成・点検した100種類の「名詞・格・自然な述語・不自然な述語」。2026-10-30作成。外部の文例集や評価seedの出力からの転載ではない。適用可能な権利の範囲でCC0-1.0として提供する。独立した人間による評価は未実施。

文脈を補わない、文字どおりの日常的な意味を判定条件とする。「水を飲む／水を読む」のような対で、比喩・擬人化・物語設定での可否を一般的な単語禁止へ拡張しない。場所を示す「図書館で読む」等は目的語を省略した通常の解釈。モデルが答えやすい不自然な組合せに偏り、「飲む・履く・咲く」等を負例に多用している。自然な候補間の微妙な相性や、別の格なら自然になる対照は不足し、完成した採用試験ではない。

このTSVは評価専用で、修正文や学習用の正例として使わない。推論や配布モデルには含めない。9種類は現行語彙に必要な語形がなく、確率診断から除外した。結果を見て語形を置き換えて点数を上げてはいない。

`scripts/audit_combinations.py` でSudachiの正規化形による共起と語彙IDを調べ、`scripts/prepare_combination_holdout.py` で将来の再学習用splitを準備する。辞書は既存データ準備と同じSudachiPy / SudachiDict-core。由来・バージョン・SHA-256・除外理由は[診断JSON](../../docs/everyday-v13-combination-audit.json)を参照。

本文の転載やモデル変更を行わず、親コーパスの出典・ライセンスは準備manifestに継承する。語彙は元のIDとmetadataを保持するので、語彙自体を未知とする評価ではない。研究結果と限界は[v13記録](../../docs/combination-generalization-research.md)。
