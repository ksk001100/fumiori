# 小型モデルの修正学習用データ

`edits.json` はCodexが学習用出力から選び、複数の修正文を作成・点検した注釈。独立した人の評価ではない。推論には一切配布しない。

元の出力はv11の通常学習モデル（seed 811000〜811383）と追加学習モデル（810000〜810255）から収集した。開発評価820000台・確認用830000台・前回評価730000台を誤り収集に使わない。編集前の文は学生モデルが生成したものであり、特定の元コーパスの文との対応は未確認。

`prepared/` は実際に使った語彙ID・元文・複数の修正文・棄却対象を含む保存用snapshot。train 34種類・92修正文、validation 9種類・23修正文。prefix単位でsplitを分け、親コーパスのvalidation/test/family-testに本文が一致する修正文は除く。語彙を増やさず、既存の表記・かな・品詞と一致する修正だけを使う。

語彙・親manifest・各split・元出力・注釈のhashは `prepared/manifest.json` に記録した。元モデル・コーパスの出典は親manifestを継承する。由来にはTatoeba、元の対応付き散文、LLM-jp教師文、Sudachi辞書が含まれるため、データ全体を出典のないCC0素材として扱わない。

注釈は元出力のindex、修正前に残すprefix、自然なsuffix候補を指定する。prepare時に単語境界・読み・語彙・保護された本文を検査する。これは今回の研究データであり、採用済みモデルの例文集ではない。結果は [v12の研究記録](../../docs/compact-repair-research.md)。
