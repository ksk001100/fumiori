# 次に試すモデル改善案

記録日: 2026-10-29、状態更新: 2026-10-30。以下は実験計画であり、完了した部分と未実施の比較を各項目に記載する。結果は別の実験記録に保存し、この計画の状態とリンクを更新する。

## 維持する目標

- 配布する重み・語彙・設定・manifest・LICENSEの合計3,000,000 bytes以内。
- normalのお題1件100ms以内を目標に、実CPU/WASMでウォームp50/p95を測る。ロード・描画とは分ける。
- 自然な日本語と文脈に合う読み、話題・文体の多様性を保つ。童話調や代名詞始まりへの集中も調べる。「自然」は自然な文章の意味で、風景や動植物を除外しない。
- 学習モデル主体。固定文型、全文一覧、修正表、教師LLMを推論に持ち込まない。
- seedが異なればほぼ重複しない状態を目指す。履歴なしの重複と、学習文にない正規化本文を別に測る。

## 出発点

[v12](compact-repair-research.md) では、修正した34種類のprefixの誤り確率は下がったが、別の9種類には転移しなかった。修正SFT＋ULの自然さ93/100は比較用92/100との差が小さく、改善の証拠には不足。新規率も約57%にとどまる。4bit候補は2.80MB・ブラウザーp95約42msを実現したが、自然さ81/100だった。

次は個別の修正文の暗記から、**既知の単語を未見の組合せでも自然につなぐ能力**へ評価と学習の焦点を移す。

## 優先1：語の組合せを分けた評価を作る

仮説: 通常の文単位splitだけでは、単語の相性を学んだのか、似たprefixを覚えたのかを区別しにくい。

1. 名詞と述語をそれぞれ含む自然な文と、不自然な組合せを対で集める。同じ名詞でも格や文脈が変われば自然になる場合を残し、単語単体を禁止するラベルにはしない。
2. 学習には各単語が現れるが、確認側の「名詞・格・述語」の組合せ自体は現れないsplitを作る。語形変化や言い換えによる重複も確認する。
3. 今回の9種類から、少なくとも100種類の確認用の組合せを用意することを目安とする。ラベルの曖昧さを点検し、作成者と独立した評価かどうかも記録する。
4. 正しい続きへの確率、誤った続きへの確率、自然な代案の保持を測り、別seedでの自由生成も評価する。

**注意:** 現行checkpointは元コーパスの組合せを既に学習している。後から例を隠すだけでは未見にならない。組合せを本当に未見として評価する比較は、全学習ソースから該当例を除き、共通の初期値から学び直す。教師の事前学習での既知・未知までは保証せず、タスク学習での未見として報告する。

実施状態: 2026-10-30に[v13](combination-generalization-research.md)で100対と共起検査、再学習用の除去splitを作成。既存語彙で91対を診断したが、自然側86種類は元trainに共起があり、未見への転移とは扱わない。除去後の構成語被覆は96/100。係り受け・同義表現の漏洩検査と評価例の拡充、共通初期値からの再学習比較は未実施。

続く[v14](compositional-generation-v14.md)では共通の乱数初期値から通常CEと平滑化CEを再学習し、91対の確率・prefix生成・各600要求の自由生成を比較した。平滑化による安定した改善は確認できず、試作2モデルは比較用としてデモへ追加した。意味漏洩の追加検査と複数候補の蒸留は引き続き未実施。

[v15](compositional-generation-v15.md)では学習文抽選と入力マスクの乱数を分け、名詞入力マスクとデータ比率を2×2で比較した。自然で読みが合うtrain非一致文は比較基準・入力マスクとも44/100で、比率変更はコピーが増加。4モデルをデモへ追加したが、標準には採用しない。単純な正則化・抽選比率では解決せず、意味の相性と自然な代案を伝える学習信号の検証が次の課題。

[v16](compositional-generation-v16.md)は分岐補正へ実際の抽選質量を反映した。コピーは同じ混合比の補正なし67.5%→43.8%へ減ったが、自然さは88/100→77/100。自然で読みが合う非一致文は29/100で、通常比率の参考44/100を超えず不採用。2モデルをデモへ追加した。既存の少量データの頻度補正を重ねるだけでは不十分で、独立した学習用入力から自然な代案の種類と意味関係を増やす検証を次の課題とする。

[v17](compositional-generation-v17.md)では新規収集用seed840100で既存ローカル教師から文を生成し、語彙を保って500件／2,518件追加した。開発評価はv15/v16の880000台を再利用し、850000台・確認用830000台は今回使っていない。同じ混合比の対照に比べ、自然で読みが合う非一致文は25→32→43/100へ増えたが、近似文を除くと8→8→14/100。新2モデルをデモへ追加した。独立した人手・生成seed・学習seedによる確認と、教師の実際の話題分布の評価は未実施。今回の全文追加は複数候補の関係蒸留ではなく、その比較に先立つ文の種類の拡充である。

[v18](compositional-generation-v18.md)ではv17の追加データを通常比率でも学び、文追加×抽選比率の2×2を完成した。コピー率は既存seedで23.5→15.5%、新seedで23.7→18.0%と低下したが、自然で読みが合う非一致文は既存seed44→57/100に対し新seed53→52/100で改善が再現しなかった。新1モデルをデモへ追加したが不採用。損失と組合せ診断の改善を自由生成品質の代用にせず、意味関係の学習信号と評価の独立性を次の課題とする。

## 優先2：複数の自然な候補の関係を蒸留する

仮説: 数十個の誤りに対する正誤ラベルだけでは、語彙全体の意味関係を伝える信号が足りない。単一の正解へ寄せず、自然な複数候補の相対的な関係を伝える方が転移するかもしれない。

- 学習側のprefixに対し、元の正しい続き、学生が選びやすい候補、異なる意味・表現の代案を集める。
- 教師の単純なA/B判定はv12で信頼性が不足したため、そのまま教師ラベルにしない。候補の対比較や継続文のスコアを、位置・提示順を変えて点検する。既知の自然な例と不自然な例で十分な一致が得られなければ、この自動ラベル作成方法は採用しない。
- 複数の自然な候補への確率配分、または候補間の相対logit差を学生へ伝える。教師が一つだけ高得点にした候補へ収束しないよう、代案の被覆率と多様性も測る。
- 元コーパスのCEを残して文法の退行を抑える。誤り抑制を加える場合は、曖昧な負例や自然な他の続きまで過度に下げないか確認する。
- 教師・候補表・補助lossは学習時だけ使い、実行時のモデル構造と配布サイズを維持する。

最初の比較は、同じ構成・初期値・データ抽選・学習量で、①通常CE、②複数修正SFT、③複数候補の蒸留を比較する。負例抑制の有無や強さは別の比較にし、一度に変更しすぎない。

参考はv12で確認した [Multi-Response Training](https://arxiv.org/abs/2606.00544) と [Concrete Score Distillation](https://proceedings.iclr.cc/paper_files/paper/2026/hash/1bfc9f74afa91b9b8add5a97a97001a1-Abstract-Conference.html)。既存研究の完全再現や、この組合せの研究上の新規性は主張しない。この用途で効くかを確かめる仮説である。

実施状態: 設計案のみ。候補の採点方法・教師・lossの詳細は、評価データと教師の信頼性確認後に固定する。

## 優先3：容量配分と量子化の影響を分ける

仮説: v12の4bit候補は本体・混合比・量子化が同時に変わったため、自然さが下がった原因を特定できていない。

- 同じデータ比・初期値・学習量の構成について、学習後4bit化とQATを比較する。
- 量子化前後のlogit・lossの差と、実際の自然さ・新規率・重複を分けて測る。FP32版は診断用として扱い、配布3MBの候補とは区別する。
- 語彙サイズを固定して幅と層数の配分を比べる。代名詞始まりの増加などが、本体ではなくデータ比で説明されないか確認する。
- 3MB内でも遅い構成は候補から外す。各モデルで実ブラウザーの通常生成時間を再測定する。

実施状態: 未着手。優先2の小さな比較で転移の見込みを確認してから広げる。

## 評価と採否の進め方

- 既に点検した730000台・820000台を、新しい修正ラベルの収集へ流用しない。既存の学習用810000台・811000台は由来を保つ。
- 次の新規収集用に840000〜849999、開発評価に850000〜850599を予約する。未使用の830000〜830599は、開発条件を満たした候補だけの確認評価として残す。使う前に既存レポートとの重複を確認する。
- 各比較は600seed、easy/normal/hard各200件、同一の生成設定、履歴なしを基本とする。点検する100件は出力を見る前に選び、全件と判断理由を保存する。
- 新規率の参照集合に、通常の学習文だけでなく修正文・蒸留に使った完成文も含める。確認用データは学習しない。
- 事前の目安は自然さ・読み95/100以上、新規正規化本文95%以上、異なるseedでの固有本文99%以上。これは現時点の達成値ではない。容量と速度も同時に確認し、100件点検の誤差や評価者の限界を明記する。
- 学習例だけの改善、確認側での悪化、多様性の低下、教師ラベルの不安定さがあれば不採用と記録する。都合のよいseedや設定だけで改善扱いにしない。
- 差が小さい候補は複数の学習初期値でも確認する。品質や多様性が不足する段階で探索規模だけを増やさない。
