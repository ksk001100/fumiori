# 限界

現行モデルは **stories-v1-3mb**。

- 独立した人間の品質評価は未実施。無作為抽出100文のCodex点検では自然さ・読みの両方に合格したものが90文。不自然な構文や「降ります」などの文脈依存の読み間違いが残る。
- 日本語SimpleStoriesの合成物語に依存し、童話調・擬人化・幻想的な題材への偏りがある。一般的な実用文の品質は保証しない。
- 人名・固有名詞の品詞と「文字」トークンは生成から除外する。かな一文字ずつで名前を綴る経路を防ぐが、一般名詞と同じ表記の人名を文脈で識別する仕組みではない。辞書にない通常のかな語も生成対象外になる。上記の品質測定はこの制限を追加する前の結果。
- 学習文との一致や出力の重複は起こる。正規化本文の新規率は意味的な独立性や未見文型への汎化を保証しない。
- 字種・長さ・区切りの整合性・局所的な境界チェックは、意味や文脈的な読みの検証ではない。未知の漢字と読みを自由に創作するモデルではない。
- 約2.90MBはモデル配布物の合計。実行ファイル、WASM/JS、実行時メモリは別。INT8は保存形式のみで、計算はFP32。KV cacheもない。
- 他OS・全CPU・全ブラウザの互換性や性能は未検証。静的fallbackは無効で、生成に失敗する場合はエラーを返す。

測定条件、採点、出典と全出力は [3MBモデルの説明](three-mb-generation.md) を参照。
