# Phase 1：標準モデルのベースライン

2026-10-30。実装・定義・後続計画は[現状分析](compositional-generation-phase1.md)。今回の測定はモデル改善前の出発点であり、学習や推論方式の改善実績ではない。

## 測定条件

標準配布INT8モデル `stories-v2-diverse-3mb`、2,624,832パラメータ、配布5ファイル2,903,289 bytes。重みSHA-256は `5dd650cb062798a43a841dd26ef1d450902255e1c0a587a76cc95a39576a028b`。生成はCandleのCPU FP32、Windows x86_64、Intel64 Family 6 Model 183 Stepping 1、release CLI、rustc 1.98.1。メモリ使用量は測定していない。

両条件ともtemperature0.8、top-p0.95、履歴0、要求ごとに独立seedを設定し、履歴を消去する。かな長・語境界等の既存の生成制約は維持し、学習文の一致・自然さ・読みを理由とする事後の出力除外はしない。

混合条件はseed860000〜860599でeasy/normal/hard各200要求。速度探索用のnormal条件はseed861000〜861089の90要求。設定は[JSON](../configs/novelty-baseline-v1.json)。生成とテストを同時実行した最初の探索測定は `build/novelty-baseline-v1` に保持し、以下にはテスト終了後に取り直した `build/novelty-baseline-v1-final` を用いた。文字列の指標は両実行で一致した。

コピー参照は標準モデルのtrain 30,800文のみ。完全一致はNFKCと末尾句点のみの正規化であり、従来の副詞や時刻を除く本文新規率とは異なる。近似一致は文字bigram集合Dice係数0.8以上。短い日本語では自然に共通する語尾や助詞も多く、この値だけで暗記を証明するものではない。一方、完全一致を除いた30%にも類似性があるため、完全一致だけではコピー傾向の診断が不足する。

未知単語0の混合条件でも未出現の既知語ペア30箇所を測定できた。ただし助詞を含む表層の隣接語の診断であり、「主語・場所・動詞」の意味的な組合せ一般化を証明しない。normalの単語未出現2箇所も、固定語彙の学習splitで未観測な表層形であり、新語を自由に創作した結果ではない。

Self-BLEUは参照集合の大きさと難易度に依存するため、600件と90件の大小をモデル性能差と解釈しない。既存の履歴16の確認600件とも生成プロトコルが異なるため、今回の差を改善・悪化と判定しない。

normalの測定p95は今回100ms以内だったが、90要求の探索測定であり、他端末や長時間運用での上限の保証ではない。初回生成と失敗も含める既存CLIの計測で、モデルload・ダウンロード・描画・評価コードは含まない。厳密なウォーム生成のみの時間やブラウザーの時間として扱わない。

## 自然さと読みの点検

混合600要求から、出力を選別しない固定乱数9021で100件を抽出した。今回Codexが全100件の本文とかなを読み、文法・意味と読みを別々に点検した。[評価票CSV](novelty-baseline-v1-agent-review.csv)と[hash付き集計JSON](novelty-baseline-v1-agent-review.json)を保存した。

| 点検者 | 自然さ | 文脈に合う読み | 両方合格 |
|---|---:|---:|---:|
| Codex（agent） | 91 / 100 | 99 / 100 | 90 / 100 |
| 独立した人間 | 未実施 | 未実施 | 未実施 |

これは自動評価器や独立した人間の得点ではなく、主観を含むagent点検。モデルや採点基準の開発者から独立した品質の証明にはならない。点検済み100件を修正学習へ流用して、同じ標本で改善を主張しない。

[人手評価用の未記入CSV](novelty-baseline-v1-human-review.csv)を別に保存した。本文・かな・標本hashを保持し、属性を `independent_human` として記入する。agentの採点を人間の評価として合算しない。自動の自然さ／文脈読み欄は測定JSONでnullのままとし、構造検証を代用しない。

### 成立する例と残った失敗

| 要求番号 | 本文／かな | 点検理由 |
|---|---|---|
| 75 | 子どもは地図を広げた／こどもはちずをひろげた | 文法・意味と読みが対応する例 |
| 152 | 学校で借りた図鑑を読み終えたので返しに行く／がっこうでかりたずかんをよみおえたのでかえしにいく | 複数の動作と理由がつながる例 |
| 121 | みんなで笑顔にしますからです | 「しますからです」の接続が不成立 |
| 157 | 波の音が心を楽しく漂う | 格と意味の対応が不自然 |
| 191 | ある日、森で大きなケーキを見つけましたと、空に大きな木がありました | 丁寧形の後の「と」の接続と場面の関係が崩れる |
| 324 | 毎日、絵本を食べる | 通常の字義的な解釈では語の意味関係が成立しない |
| 391 | 友達と一緒に教室を読む | 読む対象として教室は不整合 |
| 393 | 彼は本を開いた／かれはほんをあいた | 他動詞の文脈では「ひらいた」が適切。構造は合格しても誤読する |
| 591 | と学びました | 引用を受ける前半が欠ける |

「物語を棚にしまう」は本の換喩なら解釈可能だが、単独のお題として不明瞭なため安全側で不合格にした。「雲が空を飛んでいた」等は童話的な比喩として許容しており、字義的な日常文の基準なら判定が変わる。「笑顔で降りて、笑顔でした」の冗長な反復も不合格とした。境界的な判断は全件CSVの理由を参照し、基準依存の部分を隠さない。
